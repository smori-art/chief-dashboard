# 画面仕様書

## 共通フィルタ (サイドバー)

全ページ共通で以下のフィルタを提供:

| フィルタ | タイプ | デフォルト |
|---------|--------|-----------|
| 期間 (From-To) | 月/日粒度切替可 | 当月 |
| 店舗 | 複数選択 | 全店舗 |
| 部門 | 複数選択 | 全部門 |
| 分類 (大/中/小) | カスケード選択 | 全分類 |
| 売上表示 | 粗売上/実売上切替 | 実売上 |

## ページ構成

### 1. Executive Summary (全社概況)

**目的**: 経営層が月次の全体状況を一目で把握

#### 1.1 KPIカード (上部)
- 売上 (今月実績 + 着地見込み) | 前年差 | 前月差
- 粗利額 | 粗利率 | 前年差
- 値引額 | 値引率
- 欠品率 (レシート推定)
- 廃棄額 (※データなければ「データ未取込」表示)
- 在庫金額

#### 1.2 部門別構成比 (中段)
- 売上構成比: 横棒グラフ + テーブル
- 粗利構成比: 横棒グラフ + テーブル

#### 1.3 トレンド (下段)
- 月次売上推移 (粗売上/実売上、前年重ね合わせ)
- 月次粗利率推移
- 粗利悪化の要因分解 (ウォーターフォールチャート)

### 2. Department View (部門分析)

**目的**: 部門長が担当部門の問題を特定

#### 2.1 部門選択タブ
- 食品 / 青果 / 鮮魚 / 精肉 / 惣菜 / 店舗管理

#### 2.2 部門KPIカード
- 売上、粗利、粗利率、値引率、廃棄率、欠品率

#### 2.3 ドリルダウンテーブル
- 部門 → 大分類 → 中分類 → 小分類
- 各レベルで: 売上、粗利、粗利率、前年差、ランキング

#### 2.4 ランキング
- 粗利率悪化Top10
- 値引率Top10
- 廃棄率Top10 (データあれば)

### 3. Store View (店舗分析)

**目的**: 店長・経営が店舗間の問題を特定

#### 3.1 店舗KPI比較テーブル
- 全店舗一覧: 売上、粗利率、客数、客単価、前年差
- ソート可能

#### 3.2 ベスト/ワースト
- 売上伸び率Top/Bottom5
- 粗利率Top/Bottom5

#### 3.3 店舗トレンド
- 選択店舗の月次推移 (複数店舗重ね合わせ可)

### 4. Store × Department (店舗×部門)

**目的**: 店舗部門の問題箇所を特定

#### 4.1 ヒートマップ
- 行: 店舗, 列: 部門
- 色: 粗利率 or 前年差

#### 4.2 問題箇所リスト
- 粗利悪化: 前年比-2pt以上の店舗×部門
- 欠品悪化: 前月比+1pt以上
- 値引増加: 前月比+1pt以上

### 5. OOS Analysis (欠品分析)

**目的**: 欠品による機会損失を可視化・削減

#### 5.1 欠品率サマリ
- レシート推定欠品率 vs 在庫ベース欠品率 (並列表示)
- 部門別欠品率

#### 5.2 欠品疑いSKUリスト
- SKU、商品名、部門、直近売上、期待売上、欠品日数
- 機会損失額の推定

#### 5.3 ヒートマップ
- 曜日 × 時間帯の欠品パターン

### 6. Import / Admin (データ管理)

**目的**: Excel取込と運用管理

#### 6.1 Excelアップロード
- ファイル選択 (ドラッグ&ドロップ)
- データ種別選択 (日別商品別売上, 日別店舗別売上, レシート明細, 精算データ, 時間帯別, マスタ)
- プレビュー (最初の20行)
- バリデーション結果表示 (エラー行のハイライト)
- 確定ボタン → BigQueryロード

#### 6.2 取込履歴
- インポート履歴一覧 (日時、ファイル名、行数、ステータス)
- エラーログ詳細

#### 6.3 マスタ管理
- マスタ整合性チェック (孤立SKU、未登録店舗 等)
- マスタ一覧表示

### 7. Export / Report (レポート出力)

**目的**: 社内共有用のPDF生成とTeams送信

#### 7.1 PDF生成
- 現在のフィルタ条件でレポートPDF生成
- レポート構成:
  1. サマリKPI
  2. 部門別構成比
  3. 粗利悪化Top要因
  4. 欠品/廃棄/値引の要点

#### 7.2 Teams送信
- 送信先チャネル/ユーザ選択
- PDF添付 or SharePointリンク
- メッセージカスタマイズ
